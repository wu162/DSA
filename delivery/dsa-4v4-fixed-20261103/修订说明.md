- 投降对话框 / 终结相关阵营判断改为查表
- 技能组预选和随机改为每边四席
- 海克斯符文玩家范围、战场锚点和单位效果归属适配非连续座位
- 海军补兵按双方实际席位遍历，保留每边六个出兵口
- 计分板以四行双阵营并排显示全部八名玩家，避免原脚本写超出七行
- T4 大船限额表、玩家技能书和飞机侧升级的遗漏

静态校验：保留了 478 个世界构建脚本和 63 个文件夹，二进制 RefPack 压缩后完成全字节解压回读校验。
本次变更共涉及 28 个地图脚本路径和 36 个二进制脚本 Action 参数。

注意：没有完整 8 人游戏实机验证。原地图 MPPositionList 仍为六个记录，本包不擅自改变可能与引擎协议有关的数据；S7/S8 触发区、六人空席处理及所有 UI 行为仍需实机验收。

使用：复制整个 DSA_XXX%COR_44 目录进入红警3玩家地图目录，不要覆盖原 3v3 地图。不要把 ScriptsData.json 误当成游戏直接加载的主地图。
